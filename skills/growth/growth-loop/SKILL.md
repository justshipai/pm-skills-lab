# Growth loop

Funnels leak; loops compound. The difference between a durable growth engine and a treadmill of channel tactics is whether **the output of using the product feeds back into acquiring or activating the next user**. This skill designs that loop: the closed cycle, the feedback step that makes it self-reinforcing, whether it compounds, and the one constraint worth optimizing — not "do SEO + ads + referrals."

## The judgment this skill encodes

- **A loop is closed; a funnel is a line.** Draw the cycle where a step's output becomes a later step's input (e.g. user creates content → content ranks/shares → brings new users → who create content). If it doesn't loop back, it's a funnel/channel, not a loop.
- **Name the loop type and the engine.** Viral/invite, content/UGC, paid (LTV recycled into CAC), sales/word-of-mouth, integration/network. The type determines the math and the constraint.
- **Does it actually compound?** State the condition: a viral loop only compounds if k > 1; a paid loop only if LTV > CAC and payback is fast enough to recycle. If it doesn't compound, say so — it's a one-time channel, not an engine.
- **Find the constraint (the rate-limiter).** A loop is only as fast as its slowest, leakiest step. Identify the step that most throttles the cycle (the bottleneck) — that's where to focus, not the whole loop at once.
- **Cycle time matters as much as conversion.** A loop that turns over in a day beats one that turns over in a month even at lower conversion. Note the loop's speed.
- **One core loop, then maybe a secondary.** Most products have one dominant loop; chasing five at once dilutes. Identify the primary engine first.
- **Tie it to the product, not just marketing.** The best loops run *through the product* (using it creates the growth input), which is why they're defensible — not bolted-on campaigns.

## Process

1. **What does using the product produce** that could attract or activate the next user? (content, invites, data, network value)
2. **Draw the loop** — the closed cycle of steps, output → input.
3. **Type & engine** — which loop, and what powers it.
4. **Compounding check** — the condition under which it grows (k>1, LTV>CAC, etc.); does it hold?
5. **Constraint** — the slowest/leakiest step that rate-limits the loop.
6. **Cycle time + what to optimize first** — and any secondary loop.

## Output format

```
# <Product> — Growth Loop

## The loop                 (the closed cycle: step → step → … → back to input)
## Loop type & engine        (viral / content / paid / sales / network)
## Does it compound?          (the condition — k>1, LTV>CAC, etc. — and whether it holds)
## The constraint             (the rate-limiting step to optimize)
## Cycle time                 (how fast it turns over)
## Optimize first / secondary loop
```

## Anti-patterns to refuse

- A list of channels/tactics (SEO + ads + referrals) → Draw the closed, self-reinforcing loop.
- A linear funnel labeled "loop" → Show the step where output feeds back to input.
- Asserting it'll "go viral" with no condition → State the compounding condition (k>1) and whether it holds.
- Optimizing the whole loop at once → Find the rate-limiting constraint.
- A bolted-on marketing loop ignoring the product → Run the loop through product usage.
